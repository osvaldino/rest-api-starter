## 🎯 Como Usar

### Para o Orquestrador
Sempre analise a demanda e consulte os arquivos dos especialistas apropriados antes de delegar trabalho.

### Para Especialistas
Consulte seu arquivo específico para entender suas responsabilidades, padrões e colaborações esperadas.

### Para Desenvolvedores
Use esta documentação para entender como as demandas são processadas e qual especialista acionar para cada tipo de tarefa.
